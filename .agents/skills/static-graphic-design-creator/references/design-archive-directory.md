# Graphic-Design Archive Directory

Use this directory only when the user asks for historical or visual research, or when a specific design question materially benefits from an archive reference. Ordinary briefs do not trigger archive browsing. Check that the active host can open the source before relying on it; availability in one session does not guarantee access in another.

## Free-to-browse discovery links

| Archive | Link | Best use |
| --- | --- | --- |
| [Poster House Online Collection](https://collection.posterhouse.org/collection/) | Poster-focused catalogue with browse and search routes for exploring posters by subjects and catalogued attributes. | First choice for a poster-specific visual reference. Open an individual object record and verify its metadata. |
| [Europeana Posters](https://www.europeana.eu/en/collections/topic/49-poster) | Cross-institutional discovery page for poster records from participating collections. | Finding varied examples across institutions and countries. Follow through to the individual object and holding institution. |
| [Rijksmuseum Collection](https://www.rijksmuseum.nl/en/collection) | Museum collection search with individual object records, including historical prints and posters. | Historical objects where the record, maker, date, or collection context matters. Search and inspect the specific object page. |
| [Pentagram Archive](https://www.pentagram.com/archive) | Pentagram's public archive describes 2,000+ projects spanning 1972 to the present. | Contemporary studio case studies in identity, campaigns, publications, posters, and digital work. Treat it as the studio's portfolio, not an independent museum catalogue. |

These archive pages were checked on 2026-09-24. This does not establish continuing access to every item, image, or host session. Pentagram's page is dynamically rendered; the text-search view in the research session did not expose its interactive project browser, so confirm that the active host can inspect a specific project before citing its design details. The Letterform Archive online catalogue showed temporary maintenance during that session and is not listed as an active source; recheck access before adding it.

## Use and rights

The directory is a discovery aid, not a licence catalogue. Free browsing does not establish permission to download, reproduce, publish, or redistribute an image. Check rights on the individual record and the holding institution's or studio's current terms. Cite the specific object or project record used, distinguish catalogue facts from visual analysis, and translate only abstract design properties into an original direction. Do not download, bundle, redistribute, or embed archive images in the Skill.

Follow [Design Reviewed archive](design-reviewed-archive.md) for the shared research workflow, citation practice, limits on inference, and rights handling. If a source is unavailable or an item cannot be verified, state that limit and continue from accessible references when they are sufficient.
